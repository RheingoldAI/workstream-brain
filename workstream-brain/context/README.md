# context/

Layer 3 — the durable activity record. Auto-generated by `/daily-context`.

- `daily/<YYYY-MM-DD>.md` — per-day capture of workstream-relevant meetings, emails, and chat. Named attribution, paraphrased, **never verbatim**. Idempotent: re-running a day **merges**.
- `rolling/last-7-days.md` — a synthesis across the last 7 daily files. Idempotent: **regenerated from scratch** every run.

> **Fictional example** content below this folder. When adapting, delete the example day files; the rolling rollup regenerates on the next run.
